# Language Learning App – SVG Icon Set

- 4 icons: listen/headphones, speak/microphone, recording playback/play, settings/gear
- Each icon is supplied at 24dp and 32dp.
- Style: minimal slate blue-gray outline, no enclosing circle.
- Color: #596B87
- SVG viewBox: 0 0 24 24 (the 32dp files render the same vector geometry at 32dp).

Android note:
For Android VectorDrawable conversion, dp dimensions can be mapped directly from each SVG's width/height.
