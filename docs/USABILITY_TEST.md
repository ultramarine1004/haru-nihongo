# 50대 사용성 테스트 키트 — 하루 일본어 대화

## 목적

"50대 취미 학습자"가 **설치 후 3분 안에 첫 대화를 따라 말하고 완료할 수 있는지** 확인한다.
기능 검증이 아니라 **부담 없이 따라 할 수 있는지**를 보는 테스트다.

## 참여자

| 항목 | 기준 |
|---|---|
| 인원 | 5명 |
| 연령 | 55~70세 |
| 조건 | 스마트폰으로 카톡·사진 정도는 사용, 일본어 독학 관심 있음 |
| 제외 | 앱 개발/UX 직무 종사자, 일본어 상급자 |

## 준비물

- APK 설치된 안드로이드 기기 (`install-to-device.ps1` 사용)
- 조용한 장소, 진행자 1명, 관찰자 1명(메모 담당)
- 화면 녹화 동의서, 설문지(아래 항목)
- 돋보기/이어폰은 참여자가 평소 쓰는 것을 그대로 사용

## 진행 규칙 (진행자용)

1. "정답을 찾는 테스트가 아니라, 앱이 어떤지 보는 테스트입니다"라고 먼저 말한다.
2. **가르치지 않는다.** 막히면 "지금 어떻게 생각하셨어요?"라고 묻는다.
3. 10초 이상 멈추면 도움 요청으로 기록하고, 그다음에만 안내한다.
4. 틀렸다고 말하지 않는다. "잘 해보셨어요"라고 반응한다.
5. 모든 과제는 **사용자가 스스로 완료**하도록 둔다.

## 과제 시나리오 (1일차, 약 10분)

| # | 과제 | 성공 기준 | 측정 |
|---|---|---|---|
| 1 | 앱을 켜고 온보딩을 끝까지 진행 | '시작하기'를 눌러 홈 진입 | 소요 시간, 이탈 여부 |
| 2 | 기본 모드가 무엇인지 말해 보기 | "일반인"이라고 답함 | 인지 여부 |
| 3 | 오늘의 대화 전체를 듣기 | 🔊 버튼을 누르고 A/B 소리를 들음 | 버튼 찾는 시간 |
| 4 | 따라 말하고 내 목소리 듣기 | 🎤 → ▶ 순서로 완료 | 완료율, 도움 횟수 |
| 5 | "학습 종료하고 앱 닫기" 누르기 | 기록 저장 후 앱이 종료됨 | 완료율 |

## 7일차 후속 체크 (리텐션)

- 앱을 다시 열었는지 (자발적 재방문)
- '복습' 탭을 찾았는지
- 모드를 바꿔 봤는지 (예: 상점 주인·손님)

## 관찰 체크리스트

| 관찰 항목 | 기록 |
|---|---|
| 글자가 작다고 느꼈는지 (눈을 찌푸림, 기기 가까이 봄) | ☐ |
| 버튼을 찾지 못해 화면을 스캔한 시간 | ___ 초 |
| "이게 맞나요?" 도움 요청 횟수 | ___ 회 |
| 녹음 권한 팝업에서 당황했는지 | ☐ |
| 속도가 빠르다고 말했는지 | ☐ |
| 로마자/뜻을 먼저 읽는지, 일본어를 먼저 읽는지 | 일본어 / 로마자 / 뜻 |
| 완료 후 표정·말투 (만족 / 무심 / 불만) | |

## 인터뷰 질문 (과제 후 5분)

1. 오늘 중 가장 어려웠던 순간은 어디였나요?
2. A/B 대화를 통째로 따라 하는 방식이 부담 없게 느껴졌나요?
3. 글자 크기와 말하기 속도는 어땠나요?
4. 하루에 한 개면 충분하다고 느끼셨나요, 아니면 더 보고 싶으셨나요?
5. 이웃/가족 모드처럼 바꿔 보고 싶은 상황이 있나요?

## 합격 기준 (MVP)

| 지표 | 목표 |
|---|---|
| 과제 4(따라 말하기) 완료율 | 5명 중 4명 이상 |
| 첫 완료까지 소요 시간 | 3분 이내 |
| 평균 도움 요청 | 1회 이하 |
| "부담 없다" 응답 | 5명 중 4명 이상 |

## 개인정보 주의

- 화면 녹화에는 개인 사진/연락처가 보이지 않도록 홈 화면에서 시작한다.
- 녹음 음성은 테스트용으로만 쓰고, 종료 후 즉시 삭제한다.
- 결과 기록은 익명 번호(참여자 A~E)로 관리한다.
