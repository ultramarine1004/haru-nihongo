## 0. 제품 정의

**포지셔닝 한 줄**
> "50대에도 부담 없이, 하루 한 편의 NHK 공식 강의를 따라 말해 보는 일본어 회화 앱."

| 비교 | Duolingo | 만능일본어 | HelloTalk | NHK 강의 페이지 | **하루 일본어 대화** |
|---|---|---|---|---|---|
| 주 타깃 | 10~30대 | 독학 전반 | 회화 교류 | 중급~상급 | **50대 취미 학습자** |
| 학습 단위 | 레벨 업 미션 | 단어/문법 사전 | 상대와 채팅 | 10분 강의 | **하루 1개 강의** |
| 진입장벽 | 게이미피케이션 과다 | 정보 과다 | 상대 필요 | 페이지 탐색 | **가입 없이 바로 시작** |
| 비용 | 부분 유료 | 부분 유료 | 부분 유료 | 무료 | **완전 무료** |
| 말하기 | 일부 | 거의 없음 | 상대 의존 | 듣기 중심 | **따라 말하기 중심** |
| 오디오 | 앱 자산 | 앱 자산 | 사용자 생성 | 공식 스트리밍 | **공식 MP3 직접 스트리밍** |

**차별화 5가지**

1. **공식 콘텐츠 48편** — 자체 제작 대화를 없애고 NHK 공식 강의 링크만 사용
2. **1개 기본 원칙** — 10문장을 강요하는 대신 1개로 성공 경험을 만듦
3. **50대 친화 UI** — 큰 글씨(18~28sp, 기본 22sp), 한 화면에 한 강의
4. **로그인 無, 광고 無** — 휴대폰 켜듯 바로 열고 바로 닫기
5. **저작권을 지키는 구조** — 대본/음성을 복사하지 않고 공식 링크로 연결

**검증 가설 3개 (무료 모델이므로 지표는 리텐션 중심)**

| 가설 | 실험 | 성공 기준 |
|---|---|---|
| "1개만 해도 충분하다"가 이탈을 줄인다 | 기본 1개 / 3개 그룹 비교 | 1개 그룹 D7 리텐션 +15%p |
| 강의를 고르는 행위가 애정도를 높인다 | `MODE` 강의 선택 사용 여부 | 7일 내 재방문 시 강의 재선택 40% 이상 |
| 큰 글씨가 끝까지 읽게 한다 | 18/22/28sp 비교 | 기본 22sp에서 완주율 가장 높음 |

## 2. MVP 기능 (MoSCoW)

| 우선순위 | 기능 | 왜 필요한가 | 최소 구현 범위 |
|---|---|---|---|
| **Must** | NHK 공식 강의 48편 목록 | 자체 제작 콘텐츠 대체 | 공식 링크 메타데이터 번들 |
| **Must** | 강의 선택 / 이동 | 원하는 강의를 바로 찾기 | 우측 상단 `MODE`, `< Prev` / `Next >` |
| **Must** | «대화 듣기» | 입이 나오려면 귀가 먼저 | 강의별 공식 MP3 스트리밍, 재생/중지 |
| **Must** | 따라 말하기(녹음·재생) | 제품 정체성 | 녹음 → «내 목소리» 다시 듣기 |
| **Must** | 공식 강의 페이지 열기 | 대본·단어 확인 | 강의 제목 아래 «NHK 공식 강의 보기» |
| **Must** | 완료 체크 + 연속일 | 다음 날 다시 오게 | 날짜 기록만, 압박 없는 문구 |
| **Should** | 아침 알림 | 복귀 유도 | 1일 1회, 끄기 쉬움 |
| **Should** | 복습 화면 | 7/14/21/30일 복습 | 지난 7일 완료 목록 |
| **Could** | 발음 채점 | 동기부여 | 점수 대신 "비슷해요/한 번 더"만 |
| **Won't (이번엔)** | AI 자유대화, 구독, 광고, 로그인, 랭킹, SNS, 서버 동기화, 대본/MP3 자체 번들 | 무료·저작권·오프라인 원칙과 충돌 또는 과공수 | — |

> 서버가 없고 콘텐츠는 공식 링크만 보관하므로 운영 비용 없이 무료를 유지합니다.

## 3. UX/UI 설계 (50대 친화)

### 화면 트리

```
앱 실행 (로그인 없음)
├─ 온보딩 (3장, 건너뛰기 가능)
│   ├─ "외우지 않으셔도 돼요"
│   ├─ 선호 모드 고르기 ← [일반인 추천] 기본 선택 (설정 호환용)
│   └─ 하루 개수 고르기 ← [1개 추천] 기본 선택
└─ 홈 [강의]
    ├─ NHK 공식 강의 1편 보기 → 공식 MP3 듣기 → 따라 말하기 → 내 목소리
    ├─ 강의 변경 (우측 상단 MODE, 언제든 변경)
    ├─ NHK 공식 강의 페이지 열기 (대본/단어)
    ├─ 복습 (지난 7일)
    ├─ 기록 (연속일)
    └─ 설정 (글자 / 개수 / 알림)
```

### 첫 3분 클릭 흐름

1. 앱 실행 → 바로 홈 (온보딩은 첫 실행만)
2. 상단 제목 «하루 일본어 대화», 좌측 원형 메뉴, 우측 `MODE`
3. 화면에 **NHK WORLD-JAPAN · 레슨 N**과 공식 강의 제목 표시
4. `MODE`를 누르면 48편 강의 선택 다이얼로그 → 원하는 강의 선택
5. `< Prev` / `Next >` 로 앞뒤 강의로 이동 (하루 1편 제한 없음)
6. 한 줄 아이콘(🔊 **대화 듣기** → 공식 MP3, 🎤 따라 말하기, ▶ 내 목소리)으로 연습
7. «NHK 공식 강의 보기»를 누르면 공식 페이지에서 대본·단어 확인
8. 좌측 상단 원형 메뉴(48dp, 흰 바탕·회색 테두리) → 팝업 사이드바에서 메인/복습/설정/종료 선택
9. «학습 종료하고 앱 닫기» → 기록 저장 후 앱 종료

### 50대 배려 디자인 원칙

| 항목 | 기준 |
|---|---|
| 본문 글자 | 18~28sp(기본 22sp), 제목 26sp |
| 터치 영역 | 48dp 이상 (플로팅 메뉴 48dp, 아이콘 버튼 60dp) |
| 화면 이동 | 상단 텍스트 버튼 + 팝업 사이드바(메인/복습/설정/종료) |
| 기본 테마 | 밝은 테마 기본(고대비), 다크모드 선택 |
| 재생 속도 | **1.0x 고정** (옵션 없음) |
| 기본 표시 | 공식 강의 제목 + 공식 페이지 링크 (대본은 앱에 복사하지 않음) |
| 피드백 | 틀려도 빨간색 금지. "한 번 더 들어볼까요?" |
| 문구 | "외우세요" ❌ → "따라 말해 보세요" ⭕ |

**이탈 위험 3곳 + 개선**

| 지점 | 개선 |
|---|---|
| 강의 고르다 멈춤 | 1번 강의를 기본으로 두고, `MODE`로 언제든 변경 |
| 인터넷이 없을 때 | 음성 대신 공식 페이지 안내 문구를 표시하고 녹음 연습은 계속 허용 |
| 녹음 권한 거부 | 권한 요청 후, 거부해도 "듣기만 완료" 허용 |

## 4. 콘텐츠 구조 (NHK 공식 링크)

### 공식 강의 48편 메타데이터

`app/src/main/assets/content/lessons.json` 에는 아래 필드만 저장합니다.

| 필드 | 예시 | 설명 |
|---|---|---|
| `id` | `lesson-01` | 강의 식별자 |
| `number` | `1` | NHK 강의 번호 (1~48) |
| `title` | `레슨1 하루상하우스는 어디예요？` | 공식 페이지에서 가져온 제목 |
| `pageUrl` | `https://www3.nhk.or.jp/nhkworld/lesson/ko/lessons/01.html` | 공식 강의 페이지 |
| `audioUrl` | `https://www3.nhk.or.jp/nhkworld/lesson/ko/mp3/audio_lesson_01.mp3` | 공식 MP3 |

- 대본, 해석, 단어 목록, 오디오 파일은 **포함하지 않습니다.**
- `tools/import_nhk_lessons.py` 로 공식 페이지에서 제목·URL만 다시 추출할 수 있습니다.
- `tools/validate_content.py` 와 JVM 테스트(`LessonsContentTest`)가 개수·번호·URL·복사 필드 부재를 검사합니다.

### 저작권 원칙

- 저작권이 있는 NHK 자료를 앱 자산으로 복사·배포하지 않습니다.
- 앱은 사용자를 NHK 공식 페이지와 공식 MP3로 연결하는 역할만 합니다.
- 공식 MP3는 스트리밍하므로 재생 시 인터넷 연결이 필요함을 화면에 안내합니다.

## 5. 기술 설계 (Android)

**아키텍처:** MVVM, 단일 모듈. 수동 DI(`AppContainer`)로 Hilt 없이 시작.

```
app/src/main/java/com/haru/nihongo/
├─ HaruNihongoApp.kt / MainActivity.kt
├─ di/AppContainer.kt
├─ domain/model/Models.kt          (Lesson, Mode, Settings, Progress)
├─ data/
│   ├─ content/ContentDataSource.kt    (assets/content/lessons.json)
│   ├─ local/ProgressDao.kt       (Room)
│   ├─ preferences/SettingsStore.kt    (DataStore)
│   └─ repository/LearningRepository.kt
├─ audio/
│   ├─ LessonAudioPlayer.kt       (공식 MP3 스트리밍)
│   └─ VoicePracticeController.kt (녹음 → 내 목소리 재생)
└─ ui/
    ├─ theme/Theme.kt
    ├─ onboarding/OnboardingScreen.kt
    ├─ today/  (TodayScreen, TodayViewModel)
    ├─ review/ReviewScreen.kt
    ├─ settings/SettingsScreen.kt
    └─ AppNavHost.kt
```

**데이터 흐름**

```
lessons.json (공식 링크 48편)
  → ContentDataSource → LearningRepository → TodayViewModel → TodayScreen
  → «대화 듣기» → LessonAudioPlayer → NHK 공식 MP3 스트리밍
  → «NHK 공식 강의 보기» → ACTION_VIEW(공식 페이지)
  → 녹음/재생 → VoicePracticeController (기기 내 임시 파일)
  → 학습 기록 → Room / DataStore (기기 내 저장)
```

**오프라인 전략:** 강의 메타데이터와 학습 기록은 기기 안에 있습니다.
대본과 음성을 번들하지 않으므로 «대화 듣기»와 공식 페이지 열기에는 인터넷이 필요합니다.
**서버·계정·동기화 없음.**

**기술 리스크 3개**

1. NHK 공식 MP3 URL 변경 → 정적 검증과 재생 오류 메시지로 빠르게 감지
2. 인터넷 연결 없음 → 녹음/기록은 그대로 동작하고 안내 문구 표시
3. 녹음 권한 거부 → "듣기만으로 완료" 대체 경로 필수

## 6. 앱 내 튜터 시스템 프롬프트 (이후 단계)

> 자유대화는 MVP 제외. "한 번 더 말해 보세요" 문구 생성·추후 확장용.

```
당신은 "하루 일본어 대화"의 일본어 튜터입니다.
[현재 강의]: {lesson.number} — {lesson.title}   (NHK 공식 강의 링크만 참고)
[학습자]: 50대 취미 학습자, N5~N4

규칙:
1. 한국어로 설명하되, 예시 문장은 일본어로만 씁니다. 영어 금지.
2. 일본어 문장은 한 번에 1개, 15자 이내.
3. 틀려도 빨간 표시·"틀렸습니다" 금지. "이렇게도 말할 수 있어요:" 로 보여줍니다.
4. 매 턴 끝에 "한 번 더 따라 말해 보세요." 를 붙입니다.
5. NHK 대본을 그대로 인용하지 말고 공식 페이지 링크를 안내합니다.
```
