## 0. 제품 정의

**포지셔닝 한 줄**
> "50대에도 부담 없이, 하루 한 편의 NHK 공식 강의 대본과 음성을 따라 말해 보는 앱."

| 비교 | Duolingo | 만능일본어 | HelloTalk | NHK 강의 페이지 | **하루 일본어 대화** |
|---|---|---|---|---|---|
| 주 타깃 | 10~30대 | 독학 전반 | 회화 교류 | 중급~상급 | **50대 취미 학습자** |
| 학습 단위 | 레벨 업 미션 | 단어/문법 사전 | 상대와 채팅 | 10분 강의 | **하루 1개 강의** |
| 진입장벽 | 게이미피케이션 과다 | 정보 과다 | 상대 필요 | 페이지 탐색 | **가입 없이 바로 시작** |
| 비용 | 부분 유료 | 부분 유료 | 부분 유료 | 무료 | **완전 무료** |
| 말하기 | 일부 | 거의 없음 | 상대 의존 | 듣기 중심 | **말풍선 따라 말하기 중심** |
| 오디오 | 앱 자산 | 앱 자산 | 사용자 생성 | 온라인 스트리밍 | **앱에 번들된 공식 MP3** |

**차별화 5가지**

1. **공식 콘텐츠 48편 번들** — NHK 대본과 MP3를 앱에 담아 언제든 학습
2. **1개 기본 원칙** — 10문장을 강요하는 대신 1개로 성공 경험을 만듦
3. **50대 친화 UI** — 큰 글씨(18~28sp, 기본 22sp), 한 화면에 한 강의
4. **로그인 無, 광고 無** — 휴대폰 켜듯 바로 열고 바로 닫기
5. **완전 오프라인** — 비행기·지하철에서도 대화 듣기와 녹음이 그대로 동작

**검증 가설 3개 (무료 모델이므로 지표는 리텐션 중심)**

| 가설 | 실험 | 성공 기준 |
|---|---|---|
| "1개만 해도 충분하다"가 이탈을 줄인다 | 기본 1개 / 3개 그룹 비교 | 1개 그룹 D7 리텐션 +15%p |
| 강의를 고르는 행위가 애정도를 높인다 | `MODE` 강의 선택 사용 여부 | 7일 내 재방문 시 강의 재선택 40% 이상 |
| 큰 글씨가 끝까지 읽게 한다 | 18/22/28sp 비교 | 기본 22sp에서 완주율 가장 높음 |

## 2. MVP 기능 (MoSCoW)

| 우선순위 | 기능 | 왜 필요한가 | 최소 구현 범위 |
|---|---|---|---|
| **Must** | NHK 공식 강의 48편 대본 + MP3 번들 | 자체 제작 콘텐츠 대체 | 추출 스크립트로 자산 생성 |
| **Must** | 말풍선 대화 화면 | 50대가 눈으로 따라 하기 좋음 | A/B 말풍선 + 후리가나 + 한국어 뜻 |
| **Must** | 강의 선택 / 이동 | 원하는 강의를 바로 찾기 | 우측 상단 `MODE`, `< Prev` / `Next >` |
| **Must** | «대화 듣기» | 입이 나오려면 귀가 먼저 | 강의별 번들 MP3 로컬 재생 |
| **Must** | 따라 말하기(녹음·재생) | 제품 정체성 | 녹음 → «내 목소리» 다시 듣기 |
| **Must** | 완료 체크 + 연속일 | 다음 날 다시 오게 | 날짜 기록만, 압박 없는 문구 |
| **Should** | 아침 알림 | 복귀 유도 | 1일 1회, 끄기 쉬움 |
| **Should** | 복습 화면 | 7/14/21/30일 복습 | 지난 7일 완료 목록 |
| **Could** | 발음 채점 | 동기부여 | 점수 대신 "비슷해요/한 번 더"만 |
| **Won't (이번엔)** | AI 자유대화, 구독, 광고, 로그인, 랭킹, SNS, 서버 동기화 | 무료·오프라인 원칙과 충돌 또는 과공수 | — |

> **무료 모델 결정:** 수익 지표 대신 **학습 완료율 · D7 리텐션**을 성공 지표로 씁니다.
> 서버가 없고 콘텐츠는 앱에 번들되므로 운영 비용 없이 무료를 유지합니다.

## 3. UX/UI 설계 (50대 친화)

### 화면 트리

```
앱 실행 (로그인 없음)
├─ 온보딩 (3장, 건너뛰기 가능)
│   ├─ "외우지 않으셔도 돼요"
│   ├─ 선호 모드 고르기 ← [일반인 추천] 기본 선택 (설정 호환용)
│   └─ 하루 개수 고르기 ← [1개 추천] 기본 선택
└─ 홈 [강의]
    ├─ 말풍선 대화 1편 보기 → 대화 듣기 → 따라 말하기 → 내 목소리
    ├─ 강의 변경 (우측 상단 MODE, 언제든 변경)
    ├─ 복습 (지난 7일)
    ├─ 기록 (연속일)
    └─ 설정 (글자 / 개수 / 알림)
```

### 첫 3분 클릭 흐름

1. 앱 실행 → 바로 홈 (온보딩은 첫 실행만)
2. 상단 제목 «하루 일본어 대화», 좌측 원형 메뉴, 우측 `MODE`
3. 화면에 **«A와 B를 번갈아 따라 해 보세요»** 안내와 말풍선 대화 표시
4. `MODE`를 누르면 48편 강의 선택 다이얼로그 → 원하는 강의 선택
5. `< Prev` / `Next >` 로 앞뒤 강의로 이동 (하루 1편 제한 없음)
6. 한 줄 아이콘(🔊 **대화 듣기** → 번들 MP3, 🎤 따라 말하기, ▶ 내 목소리)으로 연습
7. 좌측 상단 원형 메뉴(48dp, 흰 바탕·회색 테두리) → 팝업 사이드바에서 메인/복습/설정/종료 선택
8. «학습 종료하고 앱 닫기» → 기록 저장 후 앱 종료

### 50대 배려 디자인 원칙

| 항목 | 기준 |
|---|---|
| 본문 글자 | 18~28sp(기본 22sp), 제목 26sp |
| 터치 영역 | 48dp 이상 (플로팅 메뉴 48dp, 아이콘 버튼 60dp) |
| 화면 이동 | 상단 텍스트 버튼 + 팝업 사이드바(메인/복습/설정/종료) |
| 기본 테마 | 밝은 테마 기본(고대비), 다크모드 선택 |
| 재생 속도 | **1.0x 고정** (옵션 없음) |
| 기본 표시 | 말풍선 안에 일본어(후리가나) + 한국어 뜻 |
| 피드백 | 틀려도 빨간색 금지. "한 번 더 들어볼까요?" |
| 문구 | "외우세요" ❌ → "따라 말해 보세요" ⭕ |

**이탈 위험 3곳 + 개선**

| 지점 | 개선 |
|---|---|
| 강의 고르다 멈춤 | 1번 강의를 기본으로 두고, `MODE`로 언제든 변경 |
| MP3 재생 오류 | 오류 메시지 표시 후 말풍선 읽기·녹음은 계속 허용 |
| 녹음 권한 거부 | 권한 요청 후, 거부해도 "듣기만 완료" 허용 |

## 4. 콘텐츠 구조 (NHK 대본 + MP3 번들)

### 추출 결과

| 자산 | 내용 |
|---|---|
| `app/src/main/assets/content/dialogues.json` | 48개 강의, 383개 말풍선 |
| `app/src/main/assets/audio/audio_lesson_NN.mp3` | 48개 공식 MP3, 총 약 274MB |

각 대화 항목:

| 필드 | 예시 | 설명 |
|---|---|---|
| `id` | `lesson-01` | 강의 식별자 |
| `order` | `1` | NHK 강의 번호 |
| `title` | `레슨1 하루상하우스는 어디예요？` | 공식 제목 |
| `situation` | `NHK WORLD-JAPAN · 레슨 1 — …` | 말풍선 위 안내 |
| `audioAsset` | `audio/audio_lesson_01.mp3` | 번들 MP3 경로 |
| `utterances[]` | `{speaker, ja, ko, romaji, polite, tip}` | 공식 대본 한 줄 |

- 일본어/로마자/한국어 3줄짜리 공식 대본 `<p>`를 파싱해 `Utterance`로 만듭니다.
- 화자 캡션이 바뀔 때 A/B를 전환하고, 캡션이 없으면 직전 화자를 유지합니다.
- `tools/import_nhk_content.py`로 다시 추출할 수 있습니다(이미 받은 MP3는 건너뜀).
- `tools/validate_content.py`와 JVM 테스트가 개수·순서·말풍선·MP3 존재를 검사합니다.

### 사용 범위

- 번들한 대본과 MP3는 **개인 학습용**으로 사용합니다.
- 앱은 네트워크 없이 동작하며 `INTERNET` 권한을 요청하지 않습니다.
- APK 용량은 약 274MB로, 설치/업데이트 시간이 다소 걸립니다.

## 5. 기술 설계 (Android)

**아키텍처:** MVVM, 단일 모듈. 수동 DI(`AppContainer`)로 Hilt 없이 시작.

```
app/src/main/java/com/haru/nihongo/
├─ HaruNihongoApp.kt / MainActivity.kt
├─ di/AppContainer.kt
├─ domain/
│   ├─ model/Models.kt              (Dialogue, Utterance, Mode, Settings, Progress)
│   └─ usecase/FuriganaTokenizer.kt (번들 사전 기반 후리가나)
├─ data/
│   ├─ content/ContentDataSource.kt     (assets/content/dialogues.json)
│   ├─ local/ProgressDao.kt        (Room)
│   ├─ preferences/SettingsStore.kt     (DataStore)
│   └─ repository/LearningRepository.kt
├─ audio/
│   ├─ LessonAudioPlayer.kt        (번들 MP3 로컬 재생)
│   └─ VoicePracticeController.kt  (녹음 → 내 목소리 재생)
└─ ui/
    ├─ theme/Theme.kt
    ├─ common/DialogueCard.kt       (말풍선)
    ├─ common/FuriganaText.kt       (한자 위 작은 가나)
    ├─ onboarding/OnboardingScreen.kt
    ├─ today/  (TodayScreen, TodayViewModel)
    ├─ review/ReviewScreen.kt
    ├─ settings/SettingsScreen.kt
    └─ AppNavHost.kt
```

**데이터 흐름**

```
dialogues.json + audio/*.mp3 (번들)
  → ContentDataSource → LearningRepository → TodayViewModel → TodayScreen
  → DialogueCard (말풍선 + 후리가나 + 한국어 뜻)
  → «대화 듣기» → LessonAudioPlayer → AssetFileDescriptor → MediaPlayer
  → 녹음/재생 → VoicePracticeController (기기 내 임시 파일)
  → 학습 기록 → Room / DataStore (기기 내 저장)
```

**오프라인 전략:** 대본, MP3, 학습 기록이 모두 기기 안에 있습니다.
**서버·계정·동기화·인터넷 권한 없음.**

**기술 리스크 3개**

1. APK 용량 약 274MB → 설치 시간 안내, 재추출 시 중복 다운로드 방지
2. MP3 자산 누락 → 정적 검증과 재생 오류 메시지로 감지
3. 녹음 권한 거부 → "듣기만으로 완료" 대체 경로 필수

## 6. 앱 내 튜터 시스템 프롬프트 (이후 단계)

> 자유대화는 MVP 제외. "한 번 더 말해 보세요" 문구 생성·추후 확장용.

```
당신은 "하루 일본어 대화"의 일본어 튜터입니다.
[현재 강의]: {order} — {title}   (번들 대본 참고)
[학습자]: 50대 취미 학습자, N5~N4

규칙:
1. 한국어로 설명하되, 예시 문장은 일본어로만 씁니다. 영어 금지.
2. 일본어 문장은 한 번에 1개, 15자 이내.
3. 틀려도 빨간 표시·"틀렸습니다" 금지. "이렇게도 말할 수 있어요:" 로 보여줍니다.
4. 매 턴 끝에 "한 번 더 따라 말해 보세요." 를 붙입니다.
5. 번들 대본을 그대로 길게 인용하지 말고 짧은 표현으로 연습하게 합니다.
```

## 8. 비판 검토 & 개선

| 리스크 | 왜 문제인가 | 개선안 |
|---|---|---|
| 1개가 너무 적어 보임 | 무료 앱이라 "이게 끝?" 느낌 | 완료 화면에 «다음 강의 듣기» 노출 |
| APK가 큼 | MP3 274MB 번들 | 설치 안내, 재추출 시 캐시 재사용 |

| 녹음 권한 거부 이탈 | 50대가 권한 팝업에서 당황 | 권한 설명 후, 거부해도 "듣기 완료" 허용 |
| 자체 콘텐츠 제작 공수 해소 | 30편 대화 유지 비용 | NHK 공식 48편 대본/음성 번들로 대체 |
